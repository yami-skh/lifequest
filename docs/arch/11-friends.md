## Ключ игрока

- При первом включении «Друзей» телефон создаёт `playerId` (UUID) и `secret` (32 байта, crypto.getRandomValues). Хранятся в `profile.player` → попадают в резервную копию; восстановил копию — друзья на месте.
- Сервер хранит только `sha256(secret)`. Каждый запрос: `Authorization: Player <playerId>:<secret>`.
- **Код игрока** (`K7M-42Q`, 6 символов без похожих букв) — отдельный, сменяемый, нужен только чтобы друг нашёл тебя. Смена кода не рвёт существующие пары.
- Ссылка-приглашение: `…/lifequest/#/friends/add/K7M42Q` (открывает приложение/сайт с подставленным кодом).

## Что уходит на сервер

Только включённое в «Что видят друзья», раз в день (при открытии приложения) и сразу после закрытия цели:

```ts
interface WeekCard {
  name: string; level: number; streak: number;
  week: string;            // понедельник недели, YYYY-MM-DD
  days: number;            // дней с действием 0–7
  goalsDone: number; xp: number;
  areas?: { title: string; color: string; note: string }[]; // «Тело: 3 тренировки» — если включено
  skills?: string[];       // названия навыков — по умолчанию выключено
}
```

Записи, цели, заметки, фото, замеры — никогда.

## Сервер (расширение `server/`, тот же Worker)

Cloudflare D1 (SQLite), бесплатный тариф:

```sql
players(id TEXT PRIMARY KEY, secret_hash TEXT, code TEXT UNIQUE, created_at INT, last_seen INT)
friends(a TEXT, b TEXT, since INT, PRIMARY KEY (a, b))           -- пара хранится дважды: a→b и b→a
cards(player TEXT, week TEXT, data TEXT, updated_at INT, PRIMARY KEY (player, week))
reactions(from_p TEXT, to_p TEXT, week TEXT, emoji TEXT, at INT, PRIMARY KEY (from_p, to_p, week))
```

| Запрос | Что |
|---|---|
| `POST /player` | создать: `{id, secretHash}` → код игрока |
| `POST /player/code` | сменить код |
| `DELETE /player` | удалить всё о себе (кнопка «Выйти из друзей…»; нужно и для Google Play) |
| `POST /friends/add {code}` | добавить по коду (пара сразу взаимная; лимит 20 друзей, 10 попыток кода в час) |
| `DELETE /friends/:id` | убрать из друзей (у обоих) |
| `PUT /card` | своя карточка недели |
| `GET /friends` | друзья + их карточки этой и прошлой недели + реакции мне |
| `PUT /reaction {to, emoji}` | одна реакция от меня другу на неделю (🔥 💪 👏 🙌), повтор — замена |

Без переписки и без сравнения/рейтинга. Хранение: карточки старше 8 недель удаляются; игроки без входа 180 дней — тоже.

## Защита (минимум для ступени 1)

- Добавить можно только по коду (перебор: 32⁶ ≈ 10⁹ кодов + лимит попыток).
- Карточку видят только друзья; сервер проверяет пару на каждый `GET`.
- Самоотметки не проверяются: соревнования нет, накрутка обманывает только себя. Слои защиты (мастер-план §15) — до дуэлей и общих квестов.
