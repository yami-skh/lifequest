# Дерево, прогресс, разблокировки, развитие дерева

## 2. Структура дерева

```text
Персонаж mildyan
└── Направление (Area)        🧠 Интеллект
    └── Ветка (Branch)        Физика
        └── Навык (Skill)     Электричество
            ├── Цели          📖 Понять закон Ома   🛠 Собрать простую цепь …
            ├── Опыт          записи журнала, привязанные к навыку
            └── Материалы     заметки, ссылки, фото
```

- В модели это одна сущность `Node` с `parentId` и `kind` (`area` | `branch` | `skill`).
- Ветки могут вкладываться друг в друга (Кулинария → Кондитерское дело → Карамель), но цели есть только у навыков.
- Каждая цель помечена как 📖 **теория** или 🛠 **практика**. Пометка влияет только на вес, отдельных шкал нет.
- Глубина не ограничена технически. В интерфейсе рекомендуем держать не больше 4 уровней.

## 3. Прогресс — одна полоска

```
Прогресс навыка, % = Σ вес закрытых целей / Σ вес всех целей × 100
вес: 📖 теория = 1, 🛠 практика = 2
```

Пример: 4 теории из 6 закрыто, 1 практика из 3 → (4 + 2) / (6 + 6) = **50%**.

**Прогресс ветки или направления, %** = среднее по дочерним узлам, у которых есть хотя бы одна цель. Пустые узлы не тянут процент вниз.

Добавление новых целей честно снижает процент. Под полоской всегда подпись «закрыто X из Y», чтобы падение было понятным.

Рядом с полоской — маленький значок уровня навыка («ур. 4», раздел 4.4). Это не вторая шкала, а число опыта: сколько он вообще этим занимался.

## 5. Разблокировка навыков

У навыка может быть список требований:

```json
{ "requires": [ { "nodeId": "hardware", "minProgress": 60 }, { "nodeId": "bios", "minLevel": 2 } ] }
```

- Пока требования не выполнены, навык виден в дереве как 🔒 с подсказкой «что нужно».
- Записывать опыт в закрытый навык можно. Блокировка мотивирует, но не запрещает.
- При выполнении всех условий: всплывашка «🏆 Разблокировано: Сборка ПК», вибрация, запись в журнале.
