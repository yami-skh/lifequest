# XP и уровни

## 4. XP и уровни

### 4.1 Начисление XP за запись журнала

```
XP = База(тип) × Сложность × Новизна × Повтор
```

| Тип записи | База |
|---|---:|
| 📖 Изучил (прочитал, посмотрел, разобрался) | 20 |
| 🛠 Практика (сделал руками, приготовил, решил) | 40 |
| 🏋 Тренировка | 30 |
| 🏗 Проект или законченный результат | 120 |
| 🎓 Курс или книга целиком | 150 |
| 🗣 Объяснил другому (научил, помог разобраться) | 60 |

| Множитель | Значения |
|---|---|
| Сложность | легко ×1 · средне ×1.5 · тяжело ×2 |
| Новизна | первая запись этого типа по навыку ×1.5, дальше ×1 |
| Повтор | 4-я и следующие записи по одному навыку за день ×0.5 (защита от фарма) |
| Фото | запись с фото-подтверждением ×1.1 |
| Работа над ошибкой | запись, которая исправляет неудачу (раздел 4.5), ×1.5 |

Пример: «Приготовил рамен с нуля», практика, тяжело, впервые, с фото → 40 × 2 × 1.5 × 1.1 = **132 XP**.

### 4.2 Распределение по навыкам

Запись привязывается к 1–5 навыкам:

- **основной** навык получает 100% XP;
- **сопутствующие** получают по 50%.

XP поднимается вверх по дереву: XP ветки и направления = сумма XP всех навыков внутри.
**XP персонажа** = сумма XP записей, каждая запись считается **один раз** (по основной доле). Иначе сопутствующие навыки раздували бы общий уровень.

### 4.3 Уровень персонажа

```
XP до следующего уровня (с L на L+1) = 100 + 50 × L
```

| Уровень | Нужно на следующий | Всего накоплено |
|---:|---:|---:|
| 1 | 150 | 0 |
| 5 | 350 | 900 |
| 10 | 600 | 3 150 |
| 20 | 1 100 | 11 400 |
| 30 | 1 600 | 24 650 |

При 3–4 записях в день (в среднем ~50 XP за запись) это примерно уровень 12 через месяц и около 45 через год.

### 4.4 Уровень навыка (0–10)

| Ур. | XP от | Название |
|---:|---:|---|
| 0 | 0 | Незнаком |
| 1 | 50 | Знакомство |
| 2 | 150 | Новичок |
| 3 | 300 | Базовый |
| 4 | 500 | Уверенный |
| 5 | 800 | Продвинутый |
| 6 | 1 200 | Компетентный |
| 7 | 1 700 | Сильный |
| 8 | 2 300 | Эксперт |
| 9 | 3 000 | Мастер |
| 10 | 4 000 | Выдающийся |

Показывается значком рядом с полоской: «ур. 4 · Уверенный», и тонкой полосой до следующего уровня внутри значка.
Можно иметь «ур. 6» и 30% прогресса: много делал, но узко.

### 4.5 История ошибок

У записи есть исход: ✅ получилось или ❌ не получилось + что пошло не так («карамель мягкая и липкая»).

- Неудачная запись тоже даёт XP: попытка — это опыт.
- Неудачи по навыку висят в его вкладке «Опыт» отдельным блоком «Нерешённые ошибки».
- Новая запись может ссылаться на ошибку: «исправлено, поднял температуру до 170°». Тогда ошибка закрывается, запись получает ×1.5 XP, а в журнале обе записи связаны: было → стало.
