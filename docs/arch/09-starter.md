# Стартовый набор

## 13. Стартовый набор

> **С 0.10.0-beta.6 (решение Yami, 05.10.2026):** новичок не получает общее дерево. На первом запуске экран «Кем хочешь стать?» (`components/Onboarding.tsx`): выбор одного или нескольких готовых путей (`src/data/templates.ts`, «Старт» отмечен заранее) или пустое дерево. Стартовые замеры v0.4 новичку не добавляются — замеры приходят из шаблонов. Квест «Обустрой персонажа» остаётся. Ниже — прежний набор (дерево брата), он у тех, кто установил раньше; код — в истории git.

Пять направлений, по 2–3 ветки, в каждой 1–2 навыка-примера с несколькими целями. Всё можно удалить и переименовать.

| Направление | Ветки |
|---|---|
| 🧠 **Интеллект** | Языки · Наука · Чтение |
| 💪 **Тело** | Сила · Выносливость · Восстановление (сон, питание) |
| 🛠 **Практика** | Кулинария · Ремонт и инструменты · Финансовая грамотность |
| 🎨 **Творчество** | Рисование и дизайн · Музыка · Письмо |
| 💻 **Технологии** | Компьютер и железо · Программирование · Интернет и безопасность |

Стартовые метрики: вес, подтягивания, отжимания, сон.

Стартовый квест «Обустрой персонажа» → 200 XP:
1. Установить приложение на главный экран.
2. Добавить свой первый навык.
3. Сделать первую запись с фото.
4. Создать первую метрику и внести значение.
5. Сделать первую резервную копию.
