# Экраны

## 10. Экраны (mobile-first)

Навигация — нижняя панель на 5 кнопок, крупная центральная «＋»:

```
[ 🧙 Персонаж ] [ 🌳 Дерево ] [ ＋ ] [ 📜 Журнал ] [ ☰ Ещё ]
```

«Ещё»: Квесты, Достижения, Замеры, Настройки.

| Экран | Что на нём |
|---|---|
| **Персонаж** (главный) | mildyan, уровень, полоса XP, серия дней 🔥, 5 направлений с полосками, активные квесты и рубежи, последние записи с превью фото |
| **Дерево** | раскрывающийся список Направление → Ветка → Навык с полосками; «+» на каждом уровне, свайп влево — редактировать/удалить |
| **Навык** | полоска + «ур. N · Название», вкладки Цели / Опыт (с блоком «Нерешённые ошибки») / Материалы / Галерея, требования для разблокировки |
| **＋ Запись** | шторка снизу: тип (6 крупных кнопок), текст, 📷, навыки (поиск + недавние), сложность, переключатель ✅/❌ (при ❌ — поле «что пошло не так»), «исправляет ошибку…», отметка закрытых целей. Над кнопкой «Сохранить» — предпросмотр «+132 XP» |
| **Журнал** | лента записей с фото, фильтры по направлению и типу |
| **Квесты** | активные / завершённые, создание квеста |
| **Достижения** | сетка значков: полученные цветные, остальные серые с прогрессом |
| **Замеры** | список метрик со спарклайнами → график метрики с линией рубежа, «＋ значение», «🎯 поставить рубеж» |
| **Настройки** | имя, резервная копия (экспорт / импорт), напоминание о бэкапе, тема |

Требования к мобильному интерфейсу:
- все кнопки не меньше 44×44px, главное действие — в нижней трети экрана под большим пальцем;
- в «＋ Запись» сверху — 5 последних навыков одним тапом;
- тёмная тема по умолчанию (система), светлая переключается;
- вибрация и анимация при получении уровня и достижения.
