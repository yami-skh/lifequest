# Квесты и достижения

## 6. Квесты

Квест — набор шагов с наградой.

| Поле | Описание |
|---|---|
| тип | основной · побочный · еженедельный |
| шаги | свободный текст или ссылка на цель навыка (тогда шаг закрывается автоматически вместе с целью) |
| награда | XP (по умолчанию 100 × число шагов) + опционально титул |
| срок | необязательно |

Пример: «Понять основы электричества», 8 шагов, награда 500 XP и титул «Новичок в электротехнике».

Еженедельные квесты задаются шаблоном и пересоздаются каждый понедельник: «3 тренировки», «1 новое блюдо», «2 записи по Интеллекту».

## 7. Достижения

Достижение — правило над счётчиками, проверяется после каждого изменения данных.

```json
{ "id": "first_dish", "title": "Первое блюдо", "rule": { "metric": "entries", "filter": { "type": "practice" }, "op": ">=", "value": 1 } }
```

Стартовый набор:

| | Достижение | Условие |
|---|---|---|
| 🌱 | Первый шаг | первая запись в журнале |
| 📸 | Фотоотчёт | первая запись с фото |
| 📅 | Неделя дисциплины | 7 дней подряд хотя бы с одной записью |
| 🔥 | Месяц дисциплины | 30 дней подряд |
| 🧭 | Разносторонний | записи во всех 5 направлениях |
| 🛠 | Практик | 1 000 XP из записей типа «Практика» |
| 📚 | Эрудит | закрыто 100 целей |
| 🌳 | Садовник | создано 25 навыков |
| ⚔️ | Первый квест | завершён первый квест |
| 🏅 | Специалист | любой навык на уровне 5 |
| 🧙 | Мастер | любой навык на уровне 10 |
| 📈 | Личный рекорд | первый рекорд в любом замере |
| ⭐ | Уровень 10 / 25 / 50 | уровень персонажа |
| 🔧 | Работа над ошибками | исправить 5 своих ошибок |
| 🎯 | Рубеж взят | достигнут первый рубеж |
| 🗣 | Наставник | 10 записей «Объяснил другому» |

**Скрытые достижения.** У достижения есть флаг `hidden`: до получения оно показывается как «❓ Скрытое достижение» без условия. Стартовые скрытые:

| | Достижение | Условие |
|---|---|---|
| 🦉 | Сова | 10 записей после полуночи |
| 🌅 | Ранняя пташка | 10 записей до 7 утра |
| 🔁 | Упрямый | 3 неудачи подряд по навыку, потом успех |
| 🎲 | Всё и сразу | одна запись, прокачавшая 5 навыков из 3 разных направлений |

Свои достижения добавляются через форму с выбором метрики и порога, можно сделать скрытым.
