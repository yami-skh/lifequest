# Техника и сохранность

## 12. Техника

| Решение | Почему |
|---|---|
| **PWA** | ставится на главный экран телефона как приложение, работает офлайн, та же версия открывается на ПК |
| **Vite + Preact + TypeScript** | лёгкий бандл, быстро открывается на телефоне |
| **Dexie (IndexedDB)** | хранит много данных и фото как Blob, есть живые запросы |
| **Chart.js** | графики замеров |
| **JSZip** | резервная копия с фото в одном `.zip` |
| **Хостинг: GitHub Pages или Netlify** | бесплатно; сайт статический, данные на сервер не уходят |

### Сохранность данных на телефоне

Браузер может очистить данные сайта, особенно на iPhone, если приложение долго не открывали. Поэтому:

1. При первом запуске вызываем `navigator.storage.persist()`: просим браузер не удалять данные.
2. Резервная копия: `lifequest-backup-YYYY-MM-DD.zip` = `data.json` + папка `photos/`. Через «Поделиться» на телефоне её можно сразу отправить в Telegram «Избранное» или на Google Диск.
3. Напоминание на главном экране, если бэкапа не было 7 дней.
4. Импорт из `.zip` полностью восстанавливает состояние, в том числе на другом устройстве.
