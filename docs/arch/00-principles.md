# Решения владельца и принципы

## 0. Решения владельца

| Вопрос | Ответ |
|---|---|
| Имя персонажа | mildyan |
| Направления | стартовый набор из 5 направлений (раздел 13) без изменений |
| Шкалы прогресса | **одна полоска** на навык вместо трёх |
| Темп уровней | устраивает (~уровень 12 за месяц) |
| Основное устройство | телефон |
| Фото | нужны уже в v1.0 |

---

## 1. Принципы

1. **XP — это вложенные усилия, % — это покрытие.** XP растёт от любых действий. Процент растёт только когда закрыта конкретная цель навыка («понял закон Ома», «собрал цепь»). Поэтому процент нельзя «нафармить».
2. **Никаких субъективных процентов.** Нельзя руками выставить «я знаю на 60%». Процент всегда считается из целей.
3. **Одна полоска, но честная.** На экране у навыка одна полоса прогресса. Внутри практические цели весят вдвое больше теоретических: «сделал» ценнее, чем «прочитал».
4. **Дерево растёт по мере интереса.** Стартовый набор небольшой, новые ветки создаются, когда появилась тема.
5. **Общий уровень ≠ «хорош во всём».** Он показывает накопленный подтверждённый опыт. Сила по направлениям видна отдельно.
6. **Данные принадлежат владельцу.** Без аккаунтов и серверов в v1.0. Резервная копия — один файл.
7. **Запись за 15 секунд с телефона.** Если добавлять опыт дольше, им не будут пользоваться.
