## Ближайшее (2026-10-06)

- **Повторы в подсказках «Нового навыка».** Подсказки дублируют карточки «Готовые» прямо над полем (Отжимания, Приседания…) — исключать их из подсказок.
- **Пустота в «Новом действии»**, когда нет активных навыков: шторка высокая (чтобы не прыгала с клавиатурой), середина пустая. Вариант — показать там «последние навыки» для выбора в один тап. Сначала макет.
- **Список подсказок остаётся открытым после скрытия клавиатуры** (фокус в поле остаётся). Подумать, закрывать ли.

## Ранее (2026-10-05)

1. **Готовые варианты везде, где человек что-то создаёт сам.** Направление, ветка, навык, цель, замер, квест (и похожие поля): под полем ввода — подсказки из запаса, чтобы выбрать подходящее одним тапом, а не печатать.
